ufo App Store

Every stack from the Server repo, click-to-copy. Deploy one at a time and check it works before starting the next — that's the whole point of this page. Paste into Arcane's compose editor, or into a terminal as the stack's docker-compose.yml.

Once, before the stacks marked “needs ufo-net”: create the shared network — docker network create ufo-net

Stacks also need their real .env on the box (copy the template, fill it in, never paste secrets anywhere else). Full order and gates: the repo README.
